AI Safety Review Project

Project: AI Response Safety Review
Field: AI Security and Data Annotation
Level: Beginner

Objective

To demonstrate the ability to review AI-generated responses for accuracy, safety, privacy, and quality.

Review Example

Sample AI Response:
An AI assistant provides an answer containing unsupported information.

Review Process:

1. Check the response for accuracy.
2. Identify unsupported claims.
3. Check for privacy concerns.
4. Review compliance with safety guidelines.
5. Recommend corrections.

Skills Demonstrated

- Attention to detail
- AI response evaluation
- Data annotation
- Error identification
- Following review guidelines

Project Status

Beginner learning project. This is a simulated review exercise, not professional security testing.
